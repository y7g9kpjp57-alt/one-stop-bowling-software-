One Stop Bowling Software – User Guide

Quick help for setting up, sharing and running a competition.

Recommended order

1. Create a tournament
Sign in and tap + New Tournament. One of the first choices is How will entries be managed?
  • Online Entries — use this when you want to collect entries before you know the final number of teams.
  • Manual Entries / I already know my teams — use the normal setup route when the entries are already known.
2. Online entries, link & QR code
If you choose Online Entries, enter the basic event details, opening/closing date and maximum entries if required. The app switches online entries on and takes you to Admin → Online & Manual Entries. Use Share Entry Form, Copy Link Only or Show / Print QR Code. Entrants can submit more than one team in the same form.
3. Contact phone numbers are private
The public entry form can collect one contact phone number per submission. It is for the organiser to use if there is a cancellation, time change or other event issue. The number is visible in the organiser/admin entry list but is not shown publicly on tournament pages, team lists, scoreboards or shared links.
4. Review entries & continue setup
Online entries can be reviewed from Admin → Online & Manual Entries. Once you know the final entries, continue with the tournament setup. This avoids guessing group sizes, greens and rink requirements before the entries are known.
5. Add or edit teams manually
Open Teams to enter or edit team/player names. Add individual player names if you want them printed on scorecards. Manual entries can also be added from the Admin entry area if someone enters by phone, paper or in person.
6. Complete Setup
Open Setup and confirm the playing format, number of ends or target score, group settings, timings and any qualification rules. Check these settings before creating the draw.
7. Create the draw
Open Draw and create the group draw. The software can place teams automatically, or you can adjust the draw manually before moving on.
8. Greens, rinks & playing schedule
If you are using more than one green, use Split / Edit Greens & Rinks. Enter the venue names and assign groups. Rink numbers restart from 1 on each green. Then open Playing Schedule and check every game has the correct time, green and rink. Quick Team Schedule is useful for checking one team at a time.
9. Print scorecards
Open Scorecards and print the cards required for the event. These can include teams, players, rink, time, green and number of ends.
10. Give scorers access
Open Invite / Access. A scorer signs in and requests access to the tournament. Approve them as Scorer, then use Configure Scoring to give them all matches, selected matches, selected rinks or selected sessions.
11. Enter scores
Open Scores and select the correct green if required. Games are shown in rink order. Use Quick Current Total for a live score, optional end-by-end scoring, or enter the Final Score. Save the final result when the game is complete.
12. Tables & completing the groups
The Tables update automatically as final results are saved. Once every group game is final, tap Complete Group Stage & Continue to confirm qualifiers and move into the knockout stage. Where enabled, the app can balance the knockout to a standard bracket size and use byes when required.
13. Knockout & live draws
Open Knockout. You can use an automatic draw, manual selection or a live draw. Score knockout games the same way as group games. When a round is finished, use Complete Round & Continue to move to the next stage.
14. Sharing, public view & TV Display
Use Share Tournament to give people access to the public tournament view. The tournament code can also be used to follow the event. TV Display provides a public screen and can switch between group and knockout information. On iPad, Screen Mirroring can be used with a compatible TV.
15. Offline mode & automatic sync
If the internet drops during a tournament, keep working normally. Changes are saved on the device and marked as waiting to sync. When the connection returns, the queued local changes are sent online before normal live refreshing resumes. Watch the status bar for Offline, Unsynced, Syncing and Synced.
16. Backup, restore & fixing a mistake
Use Backup before major tournament-day changes if you want an additional local copy. If a result is wrong, re-open the relevant stage, correct the score and complete the stage again. If later knockout rounds depend on the wrong result, the software may clear those later rounds so the correct winner can progress. Restore Last Safe Version is also available from this guide.
17. Simple Mode
Simple Mode reduces the number of advanced controls shown on screen. It is useful for clubs or volunteers who only need the core tournament-day actions. You can switch back to the full view when advanced settings are required.
18. AI Tournament Report & Smart Promotion Poster
In Admin, AI Tournament Report creates a structured summary from the results currently stored in the tournament. Copy or download it and use it in ChatGPT for a Facebook post, website article or press report. Where available, the Smart Promotion Poster can be used to create promotional material from the tournament details.
19. Archive a finished tournament
When the competition is complete, archive it. You can still view old results, tables, scorecards and knockout information later. Active tournaments stay above archived tournaments in the list.
